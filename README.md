# 🔍 News Search Application

Веб-приложение для поиска новостей по ключевым словам с использованием NewsAPI.

## 📋 Описание

Приложение позволяет пользователям искать актуальные новости по любым темам. Оно отправляет запрос к внешнему API (NewsAPI), получает список статей и возвращает их в формате JSON.

Проект построен с использованием Node.js и Express.js с применением модульной архитектуры (разделение на сервисы, контроллеры и маршруты).

## 🛠 Технологический стек

- Node.js — среда выполнения JavaScript
- Express.js — веб-фреймворк для создания HTTP-сервера
- Axios — HTTP-клиент для работы с внешним API
- dotenv — управление переменными окружения
- NewsAPI — внешний источник новостей

## 📦 Установка

### 1. Клонируйте репозиторий

git clone https://github.com/USERNAME/REPO_NAME.git
cd REPO_NAME
### 2. Установите зависимости

npm install
### 3. Настройте переменные окружения

Создайте в корне проекта файл .env и добавьте в него ваш API-ключ от [NewsAPI](https://newsapi.org/):

NEWS_API_KEY=ваш_api_ключ_здесь
PORT=3000
Важно: Для получения API-ключa зарегистрируйтесь на сайте [NewsAPI](https://newsapi.org/) (бесплатный тариф позволяет делать до 100 запросов в день).
